# scnu_acm_rank_front

**REAME  [English](./docs/README_en.md)|[中文](./README.md)** 

`SCNU_ACM_RANK` 是华南师范大学人工智能学院 ACM 集训队队伍以及成员的排名网站， 本仓库为前端仓库

该网站旨在提高学生们对于 ICPC 以及 CCPC 等算法竞赛的热情

该网站使用 `Vue2` 开发， 使用 `ElementUI` 进行 UI 设计, 

该网站的后端地址为 ：[SCNU_ACM_RANK](https://github.com/yyym-y/scnu_acm_rank) ，`Rank` 网址为 https://acmrank.socoding.cn
